# risco-edu-fiap
Projeto de Datathon da FIAP que prevê o risco educacional de alunos do projeto Passos Magicos
# Passos Mágicos - Previsão de Risco Educacional

Aplicação desenvolvida durante o Datathon da Pós-Tech Data Analytics.

## Objetivo

Identificar alunos em risco educacional utilizando Machine Learning e indicadores educacionais, comportamentais e psicopedagógicos.

## Tecnologias

- Python
- Streamlit
- Scikit-learn
- Pandas
- Random Forest

## Modelo

O modelo apresentou:

- Accuracy: 85%
- ROC-AUC: 0.92
- Recall classe de risco: 89%
